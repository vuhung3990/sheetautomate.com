2. QUY ƯỚC ĐỊNH DẠNG & NGUYÊN TẮC LÀM VIỆC
--------------------------------------------------------------------------------

| Thư mục     | Định dạng file | Mục đích sử dụng | Nguyên tắc bắt buộc |
| :---------- | :------------- | :--------------- | :------------------ |
| `web/`      | .tsx, .ts, .css| Toàn bộ mã nguồn chạy landing page | Tự chứa (Self-contained), build sạch 0 lỗi |
| `idea/`     | .txt           | Ý tưởng mới nảy sinh trong lúc làm | Đặt tên [stt]-[tên-ý-tưởng].txt |
| `plan/`     | .md (Markdown) | Kế hoạch sản phẩm & thương hiệu  | Phân loại vào marketing/ hoặc tech/ |
| `decision/` | .txt           | Các quyết định kiến trúc/kinh doanh| Phải nêu rõ TẠI SAO QUYẾT ĐỊNH NHƯ THẾ |

--------------------------------------------------------------------------------
3. QUY TRÌNH PHỐI HỢP GIỮA CÁC THÀNH PHẦN (LIFECYCLE)
--------------------------------------------------------------------------------

                    [Ý TƯỞNG MỚI]  --> Lưu vào `idea/*.txt`
                          │
                          ▼
                  [THẢO LUẬN & CHỐT] --> Quyết định lưu vào `decision/*.txt`
                          │              (Ghi rõ lý do tại sao chọn và tại sao loại bỏ)
                          ▼
                 [KẾ HOẠCH HÀNH ĐỘNG] --> Chi tiết hóa vào `plan/marketing/` hoặc `plan/tech/`
                          │
                          ▼
                  [HIỆN THỰC HÓA]  --> Lập trình vào `web/` (Giao diện, tính năng, demo)

--------------------------------------------------------------------------------
4. HƯỚNG DẪN THAO TÁC VỚI WEBSITE (`web/`)
--------------------------------------------------------------------------------

- Cài đặt thư viện:
  $ cd web
  $ npm install

- Chạy môi trường phát triển (Dev server):
  $ cd web
  $ npm run dev

- Kiểm tra lỗi kiểu dữ liệu & Đóng gói sản phẩm (Build):
  $ cd web
  $ npm run build

- Triển khai lên Cloudflare Pages:
  + Root directory: `web`
  + Build command: `npm run build`
  + Output directory: `dist`
