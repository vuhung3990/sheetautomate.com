2. QUY ƯỚC ĐỊNH DẠNG & NGUYÊN TẮC LÀM VIỆC
--------------------------------------------------------------------------------

| Thư mục     | Định dạng file | Mục đích sử dụng                 | Nguyên tắc bắt buộc                          |
| :---------- | :------------- | :------------------------------- | :------------------------------------------- |
| `flows/`    | .json, .gs, .svg, .md | Nguồn chuẩn duy nhất các flow | Pass `validate-flows.mjs` & least-privilege  |
| `scripts/`  | .mjs (Node 20) | Kiểm định, audit, build manifest | Zero npm dependencies (chỉ built-in Node)    |
| `tests/`    | .test.mjs      | Node test VM runtime & security  | Pass 100% `node --test tests/*.test.mjs`     |
| `.githooks/`| shell scripts  | Chặn sự cố trước commit & push   | Khớp `core.hooksPath`, `chmod +x`            |
| `reports/`  | .md, .json     | Bằng chứng QA & Scorecard        | Sinh bởi `run-all-checks.mjs`, giữ minh bạch |
| `extension/`| .json, .js, .html, .css | Tiện ích Chrome MV3      | Đồng bộ `flows-bundle.json`, không eval/remote JS |
| `web/`      | .tsx, .ts, .css| Website Catalog, Workbench & Test| Tự nạp `flows/*/`, 0 findings MWG, E2E PASS  |
| `idea/`     | .txt           | Ý tưởng mới nảy sinh             | Đặt tên [stt]-[tên].txt, <= 20 dòng bullet   |
| `plan/`     | .md (Markdown) | Kế hoạch sản phẩm & thương hiệu  | Tài liệu chuyên sâu                           |
| `decision/` | .txt           | Quyết định kiến trúc/kinh doanh  | Đặt tên [stt]-[tên].txt, <= 20 dòng bullet   |

3. QUY TRÌNH TỰ ĐỘNG HÓA & ĐỒNG BỘ (FLOW LIFECYCLE)
--------------------------------------------------------------------------------

   [ĐÓNG GÓP FLOW MỚI]  -->  flows/<slug>/ (flow.json, Code.gs, appsscript.json, thumbnail.svg, README.md)
            │
            ▼
   [CI/CD TRIPLE-AUDIT] -->  validate-flows.mjs -> virustotal-audit.mjs -> ai-security-audit.mjs
            │
            ▼
   [BUNDLING & SEO/GEO] -->  generate-badges.mjs -> build-flows-manifest.mjs -> package-extension.mjs -> generate-seo-geo-assets.mjs
            │
            ▼
   [QA & PREFLIGHT]     -->  run-all-checks.mjs --ci -> preflight-guard.mjs --mode=deploy -> reports/qa-evidence-report.{md,json}
            │
            ▼
   [BUILD & DEPLOY]     -->  deploy-pages.mjs -> web/dist (Cloudflare Pages) + web/public/downloads/*.zip + Extension sync

--------------------------------------------------------------------------------
4. HƯỚNG DẪN THAO TÁC NHANH
--------------------------------------------------------------------------------

- Kiểm tra & đóng gói toàn bộ flows + SEO/GEO assets (từ root):
  $ node scripts/validate-flows.mjs
  $ node scripts/virustotal-audit.mjs --dry-run
  $ node scripts/ai-security-audit.mjs --dry-run
  $ node scripts/generate-badges.mjs && node scripts/build-flows-manifest.mjs && node scripts/package-extension.mjs && node scripts/generate-seo-geo-assets.mjs

- Chạy toàn bộ bộ kiểm thử & tạo báo cáo bằng chứng QA:
  $ node scripts/run-all-checks.mjs --ci
  $ node scripts/install-git-hooks.mjs
  $ node scripts/preflight-guard.mjs --mode=deploy
  $ node scripts/deploy-pages.mjs --dry-run

- Chạy website local (`web/`):
  $ cd web && npm install && npm run dev

- Build production (`web/dist`):
  $ cd web && npm run build

- Triển khai lên Cloudflare Pages:
  + Root directory: `web`
  + Build command: `npm run build`
  + Output directory: `dist`
